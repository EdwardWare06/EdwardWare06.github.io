01 — WHAT IT IS

What it is

An animated desktop wallpaper for Windows 11. A small C# shell puts a window into Explorer's wallpaper layer, so the storm sits behind the icons. It starts at login and pauses itself when nobody can see it.

Nothing is pre-rendered. Each bolt grows from a seed while the wallpaper runs, so the storm never loops.

02 — HOW IT WORKS

How it works

  1. Shella small C# app starts at login and lives in the tray
  2. Attachits window joins Explorer's wallpaper layer, behind the icons
  3. Inputthe window never takes focus; the shell reads the cursor and clicks at 30 Hz
  4. SceneWebView2 runs the WebGL2 storm
  5. Generateeach channel is midpoint displacement, with branches that thin out with depth
  6. Drawground, reflections, bolts and sparks, then bloom and afterglow
  7. Strikea click on the desktop drives a bolt into that spot
  8. Pauseon battery, in fullscreen apps, when a window covers the desktop, and when locked
